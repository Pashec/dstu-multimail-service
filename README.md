# **DSTU Multi-mailer(v2.0)**

Автономное десктопное приложение для автоматизированной персонализированной рассылки писем, генерации динамических обращений и умного распределения персональных вложений.

## **Предыстория и эволюция проекта**

Проект вырос из реальной прикладной задачи: регулярной массовой рассылки информационных и официальных писем по базе адресатов (студенты, преподаватели, партнеры ДГТУ).

* **Версия 1.0** представляла собой монолитный скрипт с базовым веб\-интерфейсом в браузере.  
* **Версия 2.0 (текущая)** — полноценный рефакторинг: проект переведён на модульную архитектуру, оформлен в нативное окно Windows на базе **PyWebView**, обзавёлся умным сопоставлением личных файлов по ФИО, авто-определением пола для вежливых обращений и сборкой в единый .exe без лишних консольных окон.

## **Ключевые возможности v2.0**

* **Умная персонализация**:  
  * Автоматическое определение рода/пола по имени и отчеству для подстановки обращения ({обращение} ➔ «Уважаемый» / «Уважаемая»).  
  * Поддержка шаблонизации тегов: {обращение}, {имя}, {отчество}, {фамилия} и любых произвольных колонок таблицы.  
* **Комплексная работа с вложениями**:  
  * **Персональные файлы**: алгоритм нечеткого сопоставления связывает документы с адресатами по ФИО (например, файл Купчуку П.В.docx автоматически отправится адресату Купчук Павел Владимирович).  
  * **Общие файлы**: прикрепление общих регламентов, положений и инструкций для всех адресатов сразу.  
  * **Встроенный баннер**: загрузка изображения прямо в тело HTML-письма через механизм Content-ID (CID).  
  * **Удобное управление**: возможность быстро открепить любой выбранный файл или пакет файлов в один клик.  
* **Мониторинг процесса в реальном времени**:  
  * Живой терминал логов с детальным статусом по каждому письму.  
  * Индикаторы: «Всего адресатов», «Отправлено писем», «Пропущено строк», «Ошибок».  
  * Прогресс-бар с вычислением точного процента выполнения.  
* **Нативный интерфейс**: приложение запускается в отдельном окне с кастомной темой ДГТУ, без необходимости переходить в браузер.

## **Стек технологий**

* **Backend / Core**: Python 3.12, FastAPI, Uvicorn, aiosmtplib, OpenPyXL, Jinja2.  
* **Frontend**: HTML5, Vanilla JavaScript, CSS3 (современная тёмная тема, анимации, интерактивные дропзоны).  
* **Desktop Shell**: PyWebView (системный движок WebView2).  
* **Сборка**: PyInstaller (однофайловый автономный .exe).

## **Запуск из исходного кода (для разработки)**

1. Клонируйте репозиторий:  
   git clone git@github.com:Pashec/dstu-multimail-service.git  
   cd dstu-multimail-service

2. Создайте и активируйте виртуальное окружение:  
   python \-m venv venv  
   \# Для Windows (PowerShell / CMD):  
   venv\\Scripts\\activate  
   \# Для Windows (Git Bash):  
   source venv/Scripts/activate  
   \# Для Linux / macOS:  
   source venv/bin/activate

3. Установите зависимости:  
   pip install \-r requirements.txt

4. Запустите приложение:  
   python main.py

## **Сборка в автономный .exe**

Сборка полностью настроена через файл спецификации build.spec (включает упаковку шаблонов, иконки, статических файлов и сокрытие консоли):

pyinstaller \--clean build.spec

Готовый файл **DSTU\_MultiMailer\_Pro.exe** появится в папке dist/. Он полностью автономен и не требует установленного Python на целевом компьютере.

## **Требования к данным**

### **Таблица адресатов (Excel .xlsx)**

* Первая строка должна содержать заголовки.  
* Обязательные столбцы: email, фамилия, имя, отчество (регистр не имеет значения).  
* Любые дополнительные столбцы можно вызывать в шаблоне письма через фигурные скобки, например: {группа} или {должность}.

### **Именование персональных файлов**

Для корректной автопривязки документов рекомендуется называть файлы в одном из форматов:

* Иванову И.И.docx  
* Иванов Иван Иванович.pdf  
* Иванов И.И.docx
