Руководство пользователя

1. Требования к Excel-таблице

Файл должен быть формата .xlsx. Первая строка таблицы обязательно содержит наименования колонок:
• email — электронный адрес получателя.
• фамилия, имя, отчество (регистр букв значения не имеет).

2. Определение пола и правила склонений

Программа анализирует ФИО через библиотеку pymorphy3:
• По отчеству (...вич / ...вна) автоматически определяется род и формируется корректное обращение: Уважаемый или Уважаемая.
• Если отчество отсутствует, род определяется по имени с помощью грамматических правил.

3. Автоприкрепление персональных документов

Файлы сопоставляются с адресатами автоматически:
• Название документа в косвенном падеже (например, Путину В.В.docx) приводится к начальной форме фамилии (путин) и сопоставляется с первой буквой инициала имени (в).
• Получатель из Excel-таблицы (Путин Владимир) получает точно такой же ключ, благодаря чему файл гарантированно прикрепляется строго к его письму.

4. Использование шаблонов Jinja2

В тексте письма можно указывать динамические переменные: {% raw %}
• {{ first_name }} — имя адресата.
• {{ patronymic }} — отчество.
• {{ salutation }} — форма обращения («Уважаемый» / «Уважаемая»).
• Любые другие заголовки колонок таблицы, например {{ Должность }}. {% endraw %}
